## 卡在哪、怎么解决的

### 1. VS Code 选错 Python 解释器

**现象**：代码在终端能跑，VS Code 里报语法错误。

**原因**：VS Code 默认选中了 Python 3.14，而不是我装的 3.12。

**解决**：`Ctrl+Shift+P` → `Python: Select Interpreter` → 选 3.12。

### 2. 终端站错目录，报「找不到文件」

**现象**：`python hello.py` 报 `[Errno 2] No such file or directory`。

**原因**：终端当前在 `E:\桌面\测试文件夹流程`，而代码在 `D:\AIAgent\AIAgent练习`。`python xxx.py` 里的相对路径以**终端当前目录**为基准，不是以 `.py` 文件位置为基准。

**解决**：先 `cd D:\AIAgent\AIAgent练习`，再运行。养成先看提示符位置的习惯。

### 3. Git 命令拼写错误

`congif` 写成 `config`、`-- global` 多空格、`user.email"..."` 缺空格。Git 的报错信息其实写得很清楚，只是当时看不懂。

**教训**：报错先逐字读，不要急着改。

### 4. GitHub 账号被封

**原因**：注册了两个账号（AAA-AH 和 AH-HC），触发多账号规则，两个都被封。

**解决**：提交申诉工单，说明使用计划，保留 AH-HC，删除 AAA-AH，约两天后解封。

**教训**：一个身份只用一个账号，不要为了「重新开始」重复注册。

### 5. 函数返回 None

`count_unread()` 里用了 `print` 而不是 `return`，所以调用方拿到的是 `None`。

**认知**：`print` 是给人看的，`return` 是给程序用的。这两件事必须分清。

### 6. 菜单代码写在 while 循环外面

`continue` 无处可跳，直接语法错误。原因是复制代码时把 `while` 的位置搞错了。

### 7. 中文表格对不齐

中文字符在终端占 2 列，英文字符占 1 列，`len()` 只数个数不数宽度。

**解决**：写 `pad()` 函数，用 `ord(c) > 127` 判断是否为中文，宽度 +2。

### 8. Git 不读系统代理

**现象**：`git pull` 报 `Failed to connect to github.com:443 after 21069 ms`，但浏览器能打开 GitHub。

**原因**：Git 有自己的 `http.proxy` 配置，默认不读 Windows 系统代理。代理软件（云梯）只设了系统代理。

**解决**：查到代理端口 `127.0.0.1:7897`，配给 Git：

```bash
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897
```
